## Skills Claude Code

Skill installabili in [Claude Code](https://claude.ai/code).

| Skill | Descrizione | Download |
|-------|-------------|----------|
| `pma-setup` | Crea un dossier clinico completo per il percorso PMA/IVF | [pma-setup.skill](skills/pma-setup.skill) |

### Come installare una skill

1. Scarica il file `.skill`
2. In Claude Code, vai su **Settings → Plugins** e trascina il file
3. La skill è disponibile — digita `/nome-skill` per attivarla
